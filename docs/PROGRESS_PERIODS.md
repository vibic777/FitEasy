# Периоды прогресса и календарь данных

Проверено 0.3.0/7: 15 JVM-тестов в общей выдаче (периоды/високосные даты/границы/100 лет, агрегаты/шаги/пропуски, календарь/корзина, папки/совместимость и словари), компиляция обоих клиентов и все пять форматов. Реальная визуальная проверка устройств остаётся открытой.

vibic777, 2026-10-02. Решение D-050.

Периоды: день, неделя, месяц, год, несколько лет (1–100), все имеющиеся данные, произвольный включительный диапазон. Точка отсчёта — выбранная дата; направление «До точки отсчёта» заканчивается этой датой, «От точки отсчёта» начинается ей. Месяц/год используют календарную арифметику, а не 30/365 дней. Произвольный диапазон проверяет формат ISO и начало ≤ конец; максимум 100 лет для ограничения нагрузки.

Короткие графики имеют дневные точки; свыше 120 дней — месячные, свыше 10 лет — годовые. Суммы питания, воды, шагов и активности суммируются внутри подписанного интервала. Для замеров используется последнее записанное значение интервала. Пропуски остаются пропусками. Шаги сначала вычисляются за день с выбором одного источника, затем суммируются. Группировка индексирует записи один раз вместо полного поиска для каждой даты каждого графика.

Календарь даты доступен в прогрессе для точки отсчёта и обеих границ диапазона. Он показывает наличие дневника и цветовые маркеры типов: питание, напитки, шаги, активность, замеры. Фильтр типов действует только на индикацию и подробности календаря, не удаляет и не меняет записи. Пустой день явно обозначается отсутствием данных. Выбранный день показывает число записей каждого типа. При фильтрации отдельно сообщается отсутствие выбранных типов. Корзина не считается данными. Маркеры расписаний/напоминаний сохраняются отдельно. Заметки не имеют календарной даты дневника и не выводятся по времени последнего редактирования.

Поведение общее для Android/Windows и переносимо на Linux. Фильтры/периоды — состояние просмотра; форматы SharedData, LAN и резервных копий не меняются. Проверки календарной арифметики, агрегации, источников шагов и маркеров записываются в ИСПРАВЛЕНИЯ.md. Практическая проверка интерфейса на устройствах остаётся отдельной.
