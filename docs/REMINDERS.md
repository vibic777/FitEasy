# Напоминания Android и Windows

Уточнение 2026-10-02 — SCHEDULES.md: календарь, переносимые графики и локальные привязки на строку, комментарии, звук/вибрация Android/popup, подтверждение и повторы, состояния, прерывание текущей серии и выключение. В Windows меню последнего уведомления теперь включает подтверждение/откладывание/прерывание; все активные серии доступны через календарь → управление. Тихие часы пропускают регулярное событие, повтор/откладывание сдвигается к их окончанию. Runtime хранит последнее состояние серии, не полную историю исполнения. Галочка закрытия Windows в трей управляется из профиля.

Локальное расписание: одно или несколько времён, дни недели, числа месяца, интервал N дней от startDate, необязательный конец/тихие часы. Фильтры применяются совместно; пустой список дней означает без ограничения. Числа месяца без существующей даты пропускаются. Напоминания в тихие часы пропускаются. После пропуска/выключенного устройства показываются будущие события, без серии накопленных уведомлений.

Расчёт использует часы и текущий часовой пояс устройства. Переход DST разрешается стандартным java.time: время в разрыве сдвигается вперёд, неоднозначное время использует первое смещение. Android восстанавливает расписание после загрузки, изменения часов/пояса и обновления приложения. Без разрешения exact alarms используется inexact allowWhileIdle; уведомление может задержаться. Разрешение уведомлений запрашивается при включении функции. Отложить — 10 минут по умолчанию, интервал входит в модель.

Общий редактор Android/Windows поддерживает изменение, удаление, даты начала/конца, все фильтры, тихие часы и интервал откладывания; показывает ближайшее срабатывание. Некорректные даты и числа не сохраняются.

Windows использует таймер и SystemTray уведомления. При доступном трее закрытие окна скрывает его и блокирует доступ; процесс продолжает напоминания. Меню трея: открыть, завершить, отложить последнее уведомление. При недоступном трее закрытие завершает приложение. Полный выход/перезагрузка останавливают расписание; автозапуск ещё требуется. Повторное открытие использует обычную блокировку приложения.

Android конфигурация для ресивера отдельно защищена Keystore; Windows расписание в локальной базе. Расписание не передаётся LAN и не включается в обычный бэкап.

D085 (0.4.12/32): единая тихая сводка в шторке Android — шаги (если включён шагомер), включённые напоминания, запланировано на сегодня, ближайшее, ждут ответа; кнопка «Прервать все». Windows показывает сводку подсказкой значка в трее. Обновление только по событию.

D086 (0.4.13/33): Настройки → Напоминания → «Уведомления и батарея»: выключатель сводки в шторке, будильник поверх экрана блокировки с проверкой через 10 секунд и статусами разрешений, режим экономии батареи. В сводке отдельная строка задач по расписанию.

D091 (0.4.15/35): объявлено SCHEDULE_EXACT_ALARM; страница напоминания полноэкранная с группами; дни недели кнопками Пн–Вс; звук — уведомление, будильник или мелодия звонка.

D097 (0.4.20/40): напоминания показаны карточками — название, ближайшее время, выключатель, состояние, строка свойств, действия значками; звучащее напоминание отмечено красным огоньком и строкой «Звучит сейчас» с кнопкой «Заглушить». Редактор: время выбирается часами (несколько значений), повтор — один раз, каждый день, по дням недели, по числам месяца; интервал N дней, даты и тихие часы сохранены. Сигнал: мелодия — системный тон (уведомление, будильник, звонок), звук устройства из системного выбора или свой аудиофайл до 25 МБ (копируется в приложение); громкость 10–100 % относительно громкости будильника; нарастание 0, 10, 30, 60 или 120 секунд от 5 % выбранной громкости. Своя мелодия, громкость или нарастание проигрываются службой ReminderRingService на потоке будильника не дольше 60 секунд, с паузой на время звонка; подтверждение, откладывание и прерывание останавливают звук. Без этих настроек напоминание по-прежнему звучит через канал уведомлений. Windows: звуки из папки Windows\Media или файл WAV/AIFF/AU, мелодия один раз. Ограничения: если Android не разрешил службу переднего плана, напоминание приходит обычным уведомлением; файлы неиспользуемых мелодий удаляются через час после последнего сохранения.

D103 (0.4.21/41): напоминание может принадлежать заметке (Reminder.noteId, локально). Карточка заметки показывает колокольчик с числом напоминаний; редактор напоминания — выбор заметки; карточка напоминания — строку «Заметка: …» и переход; уведомление такого напоминания открывает заметку. Удаление заметки напоминание не удаляет: оно остаётся без строки заметки.

D108 (0.4.24/44): в «Настройки → Напоминания» сверху общий выключатель: пока он выключен, ни одно напоминание устройства не срабатывает, собственные настройки каждого сохраняются. Напоминания можно передать на другое устройство отдельным разделом синхронизации.

D113 / 0.4.29/49: новая установка начинает с выключенными напоминаниями (LocalData.remindersOff=true только в первой записи новой базы; существующие данные не меняются), создание напоминания при выключенных сразу показывает подсказку «Включить / Не включать». Замещение при синхронизации возможно для выбранных разделов, по-прежнему только в одну сторону: в выбранных разделах принимающее устройство получает ровно принятое, остальные не трогаются (replaceSections). Reminder.updated — время изменения напоминания (0 у прежних): слияние берёт более позднее, мелодия устройства сохраняется. Общий код Android/Windows; SQL 2, LAN 7, Transfer 5, backup 5 прежние. Запрос выборочного замещения устройство до 0.4.29 отклоняет, поэтому обновлять оба.

D115 / 0.4.31/51: проверка кода напоминаний на расход батареи и надёжность. Android: значения, запечатанные ключом устройства, открываются один раз на процесс; будильник переставляется только у изменённого напоминания; смена часов не снимает уведомления; при открытии приложения будильники ставятся заново; звук своей мелодии будит приложение только на время нарастания громкости; экран будильника показывает последнее сработавшее напоминание. Windows: после сна компьютера или смены часов таймеры ставятся заново, пропущенное не более получаса назад показывается один раз; таймер мелодии тот же, что на Android. Данные, SQL 2, LAN 7, Transfer 5, backup 5 не менялись. Новое разрешение Android WAKE_LOCK — только на время звучания мелодии.

D116 / 0.4.32/52: значок «Напоминания» в верхней панели рядом с синхронизацией и профилем открывает «Настройки → Напоминания», как будильник в верхней панели Notio. Подтверждение синхронизации: второе устройство не спрашивает только тогда, когда на запускающем заданы все три выбора; при хотя бы одном «выбирается при синхронизации» вопрос обязателен — исключение D110 (совпадение с заданным на принимающем устройстве) снято. Общий код Android/Windows; протокол LAN 7 и форматы прежние.
