Список комплекса показывает статичный силуэт; экран выполнения — только выбранное движение. Пользователь явно выбирает технику, неизвестный свободный текст не угадывается по названию: нейтральная статичная поза и предложение выбрать пример. Предусмотреть ходьбу, плечи, кисти, стопы, сведение лопаток, приседание к опоре, сгибание руки с гантелью, планку/отдых. Это оригинальные векторные схемы, не медицинские назначения. Мужской/женский вариант — локальное оформление по устойчивому ключу карточки; техника переносится через существующий Exercise.technique, внешний вид не входит в LAN.

Статичные строки не создают таймеров. Единственная выбранная сцена обновляет только Canvas, максимум 20 fps; остановка при паузе, отдыхе, выключенных анимациях, уходе в фон и невидимости. Для неподвижной планки таймер кадров не нужен. Переключение общего оформления остаётся обязательным; анимация никогда не засчитывает повторы. Проверить оригинальные кадры и чистые координаты/правила включения, реальные аккумуляторы отдельно.

По Notio RemindersScreen/BackgroundRestriction: Android панель готовности показывает уведомления, доступ к точным напоминаниям, ограничение фоновой работы и оптимизацию батареи. Запросы — по явному действию, повторный отказ не запускает цикл запросов. Для батареи открыть системные настройки, не запрашивать исключение всем при старте. Отсутствие точного доступа оставляет inexact fallback; статус обновляется при возвращении, не постоянным опросом. Получение точного доступа перепланирует будущие события. Windows информирует о необходимости работающего приложения/трея. Нет постоянно работающей службы только для напоминаний.

Общая модель и версии переноса прежние: LAN 5/Transfer 4/backup 4/SQL 2. Linux повторно использует статичные/анимированные векторные сцены позднее. Проверки/сборки/пять пакетов и оставшиеся ограничения фиксировать по факту.

Реализовано 0.3.8/15: walk/shoulders/hands/feet/scapula/curl/plank/rest и нейтральная поза. Приседание к опоре и расширенный каталог пока не реализованы. Проверены растровые кадры/движения/варианты, остановка кадров и десять строковых наборов. Просмотрена таблица кадров; ходьба исправлена на схему сбоку. Схемы упрощённые, не точное изображение всех суставов. Выбор силуэта — защищённая локальная карта. Ключ свободного упражнения зависит от имени/техники; редактор переносит выбор при переименовании. Идентичные копии используют одно оформление.
