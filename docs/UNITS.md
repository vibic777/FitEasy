# Единицы устройства

По умолчанию л/кг/г; DisplayUnits выбирает кг/фунты, см/дюймы, л/мл/US fl oz/Imperial fl oz, км/мили, ккал/кДж. Конверсия применяется к спискам записей, карточкам энергии/воды, вводу замеров и правке записей. В базе остаются кг/см/мл/км/ккал. Настройка относится к оформлению, исключена из LAN.

Профиль роста, цели, напитки и замеры принимают выбранные единицы. Ручная активность поддерживает необязательное расстояние в км/милях; записи и отчёты сохраняют distanceKm. Поля рецептов/нутриентов и отчёты используют явно подписанные канонические единицы. Подписи части графиков/каталогов ещё требуют конверсии. Поэтому FE-019 ещё не отмечен полностью готовым. Старые неиспользуемые флаги volumeLiters/weightPounds сохранены для чтения прежних снимков.
