# Языки установщика

Решение D-046, 2026-10-02. Контрибьютер **vibic777**.

Один MSI и открывающий его EXE поддерживают en/ru/be/fr/de/es/it/zh/ja/ko. До появления мастера MSI выбирает основной код языка интерфейса текущего пользователя Windows; региональные варианты используют основной язык, неподдерживаемые — английский. Системная локаль чисел не меняет язык мастера. Для управляемой установки предусмотрен FITEASYLANGUAGE (основной код либо региональный вариант); неизвестный код также означает английский.

Статическая база MSI содержит английские строки. Общая управляемая custom action на .NET Framework 4 задаёт Unicode-параметры подписей до показа диалогов. Это устраняет ограничение кодовой страницы английского jpackage для русского/CJK. Переводы стандартных страниц берутся из локализаций WiX; тексты FitEasy и белорусский словарь находятся в репозитории. Приложение, БД, LAN и Android этим не затрагиваются.

EXE содержит окончательный managed MSI и запускает Windows Installer, сохраняя код завершения. Он не требует отдельно установленной Java; Windows 10/11 содержит используемый .NET Framework. MSI можно запускать непосредственно. /quiet (EXE) и /qn (MSI) не показывают мастер и не запускают приложение. Интерактивная галочка запуска включена по умолчанию и может быть снята.

Проверки: полнота десяти словарей, выбор региональных/неподдерживаемых языков, MSI tables/действия/условие silent, безопасное открытие мастера без установки. Результаты фиксируются в ИСПРАВЛЕНИЯ.md. Нативные системные окна Windows (UAC/кнопки MessageBox) используют язык Windows.

Фактически выполнены проверки engine-session (без Install/ExecuteAction): вызов упакованной custom action для 13 случаев, Unicode-параметры/форматирование контролов, автоматический русский на текущей Windows, условия запуска при UI 2/3/4/5 и снятой галочке. Test MSI имеет новый ProductCode и не взаимодействует с установленной версией. EXE проверен на совпадение встроенного MSI и silent-обработку неверного параметра. Внешний вид мастера и полная установка/upgrade пока не проверены.

Команды: `FitEasy.exe /quiet /norestart /lang=ru`; `msiexec /i FitEasy.msi /qn /norestart FITEASYLANGUAGE=ru`. Без /lang или FITEASYLANGUAGE интерактивный мастер определяет язык самостоятельно. Английская база MSI остаётся fallback для системных диагностических сообщений до инициализации интерфейса. Версия файла EXE: версия приложения плюс номер сборки; MSI содержит FITEASYBUILD/FITEASYCONTRIBUTOR.
