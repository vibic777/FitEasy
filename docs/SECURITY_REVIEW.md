Заведено 11.10.2026 по указанию vibic777 (D131): все выводы по безопасности записываются в этот файл, и файл ведётся

## Как вести этот файл

Правило записано в `RULES.md` («Security review is kept in a file») и в `AGENTS.md`.

- Изменение, которое касается чего-либо из списка ниже, сверяется с разделом «Что проверять» до того, как оно написано,
  и после него в этот файл вносится запись: в «Журнал проверок» — что проверено и чем, в «Находки» — что найдено.
- Новая или обновлённая библиотека: проходит раздел «Библиотеки» (известные уязвимости, контрольная сумма, права и
  адреса в собранном APK) и попадает в таблицу.
- Находка не удаляется: у неё меняется состояние — «исправлено» (с версией), «оставлено» (с причиной и чьё решение)
  или «открыто».
- Пишется только то, что проверено на самом деле. Что не проверялось — в раздел «Не проверено».
- Секреты, ключи, пароли и настоящие данные сюда не пишутся. Способ воспользоваться находкой описывается настолько,
  насколько нужно, чтобы понять исправление.

Чего касается правило: права и манифест Android; компоненты, намерения, уведомления; сеть (синхронизация, поиск
устройств, почта); шифрование, ключи, блокировка и восстановление; импорт и экспорт любых файлов; пути и адреса,
которые приходят с данными; журнал; запуск других программ; установщик; библиотеки и средства сборки.

## Что проверять

1. **Права.** Новое право — только для функции, которую включает человек; назначение записано в «Настройки → Права».
   Библиотека не должна добавлять прав: сверяется список прав собранного release APK.
2. **Компоненты Android.** Всё, кроме окна запуска, `exported="false"`. Отложенные намерения — с `FLAG_IMMUTABLE` и
   явным получателем. Что пришло в намерении извне, проверяется по виду (идентификатор, а не произвольная строка).
3. **Данные не уходят сами.** `allowBackup="false"` и `dataExtractionRules`; ничего на общем хранилище; экспорт —
   только через выбор файла человеком. Секреты — только через Android Keystore / Windows DPAPI, не в базе, не в копии,
   не в передаче.
4. **Чужой ввод.** Файл копии, файл базы, передача при синхронизации, картинка, мелодия: предел размера до чтения,
   проверка содержимого (`validate`, `validateLocal`, `validateReminder`) до сохранения.
5. **Пути и адреса из данных.** Путь, адрес или URI, который хранится в данных, перед открытием проверяется по списку
   разрешённых мест. Сетевой адрес и сетевой путь из данных не открываются никогда.
6. **Сеть.** Соединение — только по действию человека или по включённой им настройке; приём — только из локальной
   сети; до обмена данными — проверка ключа с обеих сторон; TLS с проверкой сертификата и имени. Открытый текст —
   только после предупреждения.
7. **Шифрование.** Только средства платформы; случайные числа — `SecureRandom`; сравнение секретов — за постоянное
   время; у каждого ключа одно назначение; счётчик или случайный nonce не повторяется.
8. **Экран.** Что видно без разблокировки (уведомление, экран будильника, список недавних приложений) — по настройке
   приватности.
9. **Журнал.** Только названия событий и имена классов; ни текста записей, ни адресов, ни сообщений исключений.
10. **Запуск программ.** Только постоянные команды системы, без строк из данных.
11. **Библиотеки.** Раздел «Библиотеки» ниже.
12. **Подпись и сборка.** Ключи и `keystore.properties` вне Git; после сборки сверяется сертификат APK; хранилища
    библиотек — только `google()` и `mavenCentral()`.

Как повторить:

1. Версии Android: `gradlew :app:dependencies --configuration releaseRuntimeClasspath`; Windows — файлы в
   `desktopApp/build/compose/binaries/main/app/FitEasy/app`.
2. Каждую пару «библиотека, версия» отправить в `https://api.osv.dev/v1/querybatch` (экосистема Maven). Уходят только
   названия и версии библиотек.
3. SHA-1 файла из `~/.gradle/caches/modules-2/files-2.1` сравнить с файлом `.sha1` на `repo1.maven.org`.
4. Release APK: `aapt dump permissions`, `aapt dump xmltree … AndroidManifest.xml` (права, компоненты, `exported`),
   поиск адресов `http://`, `https://` в `classes*.dex`.
5. `apksigner verify --print-certs` для обоих APK.
