# Расписания и календарь — уточнение 2026-10-02

0.3.8/15: Android панель готовности показывает разрешение уведомлений/точных алармов, ограничения фоновой работы и оптимизацию батареи; явные кнопки открывают системные настройки. Точные алармы после выдачи доступа перепланируются. Шторка показывает число включённых напоминаний и ближайшее время, без постоянной службы/опроса. Состояния UI обновляются по событиям, включая Windows. Уведомление открывает расписания и соответствующее напоминание после прохождения блокировки. Подтверждение/откладывание/прерывание отменяют текущее уведомление и повтор; следующие календарные срабатывания остаются. Ожидающее подтверждения восстанавливается тихо после загрузки/смены времени. Собственные мелодии/громкость/нарастание/отдельная остановка активного звонка пока открыты; полная Notio RingService parity не заявляется.

0.3.0/7: календарь также показывает данные дневника: питание/напитки/шаги/активность/замеры, число записей дня, фильтр типов, пустые дни и другие скрытые типы. Цветовые точки соответствуют настройкам графиков; маркеры расписаний/напоминаний сохранены отдельно. Добавлен быстрый переход YYYY-MM. Календарь выбирает точку/границы периода прогресса: PROGRESS_PERIODS.md.

vibic777 уточнил: отдельная папка «Расписания», произвольные именованные расписания (например «Понедельник»), строки графика с временем, описанием и комментарием. На любую строку можно назначить локальное напоминание. Календарь показывает наличие расписаний, назначенных и включённых напоминаний; выбранный день раскрывает строки и управление.

Расписание — переносимые пользовательские данные со стабильными ID расписания/строк. Правила дней: дата начала/конца, дни недели/числа месяца, интервал от начала; одноразовое расписание задаётся одинаковой начальной/конечной датой. Строки можно добавлять, изменять, удалять и переставлять. Копирование создаёт новые ID. Удаление расписания сохраняет tombstone, локальные связанные уведомления отменяются. Настройки напоминаний/состояния срабатываний индивидуальны для устройства и не передаются через LAN/обычный бэкап.

Напоминание строки наследует время строки и календарные правила расписания. Изменение времени/правил пересчитывает уведомления, удаление строки отменяет её уведомления. Комментарий напоминания отдельный, пустой использует комментарий строки. Настройки: включено, звук/вибрация/всплывающее уведомление, подтверждение, повторы до подтверждения либо ограниченное число повторов, интервал, тихие часы, откладывание. Прерывание останавливает текущую серию, будущие дни сохраняются; выключение отменяет всё до включения.

Состояния срабатывания хранятся отдельно, локально: запланировано/выключено/ожидает подтверждения/отложено/подтверждено/прервано. Маркеры календаря означают наличие плана/назначения и включённость, не гарантируют выдачу уведомления ОС. Android использует notification channels; фактические звук/вибрация/heads-up зависят от системных настроек. Windows — трей и системный звуковой сигнал, без аппаратной вибрации.

Совместимость: SharedData получает schedules с пустым значением для прежних JSON-снимков. .fiteasy writer version 2, reader принимает 1/2; LAN protocol 3 и новый раздел schedules, чтобы старые клиенты не теряли расписания. SQLite DDL прототипа не меняется; полноценная нормализация остаётся отдельной задачей.

Тот же пакет изменений добавляет notes — NOTES.md, отдельная галочка LAN. Календарь доступен по нажатию даты, управление расписаниями/отдельными напоминаниями — из календаря. Маркеры относятся к правилам выбранной даты; последнее состояние серии не означает исполнение всех прошлых дат. Одно напоминание на строку в текущем UI. Повторы/откладывание в тихие часы сдвигаются к окончанию. Практическая проверка ОС/перезагрузки/DST пока не выполнена.

Notio-Android изучен в ScheduleDocument.kt, CalendarPlan.kt, ScheduleNote.kt, RemindersScreen.kt и ReminderEntity.kt. Там расписание содержит строки времени/текста/комментария, календарь раскрывает события дня, настройки содержат звук/мелодию/громкость/нарастание, вибрацию, popup, подтверждение/повторы, ежедневный/недельный/месячный режим. FitEasy реализует собственную структуру, не копирует исходники. Выбор мелодии, громкость/нарастание и полноэкранный будильник требуют отдельной реализации; настройки без работающего поведения не показываются.
