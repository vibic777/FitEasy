# Каркасный редактор D069

vibic777, 03.10.2026. Заменяет прежнюю таблицу схематичных движений, не удаляет сохранённые комплексы пользователя.

## Данные и редактор

D073: суставы и предметы выбираются раздельно. После добавления предмет выбран и двигается прямо на сцене; клик в пустоту снимает выбор жеста и не двигает прежний сустав. Проекция hit test общая с отрисовкой, включая привязку/поворот. Бедро прикреплено к тазу, плечо к грудной клетке; перетаскивание крепления перемещает соответствующий корпус. Длины в режиме позы фиксированы. Сцена остаётся сверху, настройки сгруппированы под иконками с локализованными hover/long-press подсказками.

При перекрытии предметов приоритет у выбранного предмета, если точка жеста попадает в него. Другой перекрытый предмет выбирается через список. Без выбранного предмета используется глубина/поправка слоя и такой же порядок ID, что renderer.

Exercise получает необязательный RigClip версии 1: длительность 0.5–30 секунд, цикл, 1–32 ключевых кадра с устойчивыми UUID, временем и позой. Поза содержит точки скелета в нормализованной сцене 0–100 и глубину z −100..100, поворот yaw, ориентации кистей/стоп и хват. Точки: таз, грудь, шея, голова, два плеча/локтя/запястья/бедра/колена/голеностопа. Редактор показывает каркас, позволяет выбирать/перетаскивать сустав, менять глубину/поворот/кисть/стопу/хват, кадры/время/длительность/цикл, копировать и отменять. Начальные позы стоя/сидя/лёжа/планка/вис. Редактирование сцены не записывает базу на каждом движении: только явное сохранение упражнения/комплекса.

Инвентарь: гантель, штанга, турник, стул, стена, резинка, коврик и пользовательский предмет. Положение/размер/поворот, привязка к кисти или к обеим кистям для штанги/резинки. Не рассчитывать сопротивление, нагрузку или безопасность по анимации. Примеры — редактируемые авторские тестовые сцены, не программа тренировок: статичная планка, отжимание, приседание, разведение рук с гантелями, сгибание рук с гантелями, подтягивание прямым хватом.

## Движение и слои

D083 (0.4.9/29): поза дополнена необязательными headYaw и bends (сгиб пальцев стоп). Кисть и ступня имеют ручку направления на сцене; хваты open/pronated/supinated/neutral изображаются; предмет с привязкой к кисти стоит в ладони; кисть без угла продолжает предплечье. Справочник: восемь карточек, две для ступней.

D081 (0.4.7/27): каркас рисуется анатомическим скелетом, женская и мужская фигуры — взрослые спортсмены с видом спереди, сбоку и сзади. Сторона лица и груди берётся из оси корпуса и линии плеч; у лежащей фигуры уточняется по локтям, кистям и коленям. Незаданные углы кистей и стоп рисуются естественно для вида. Редактор полноэкранный, управление иконками с подсказками на десяти языках, добавлены возврат действия и зеркальное отражение позы. Данные сцены и форматы прежние; прежние абзацы D074–D078 о рисунке — история.

D078 (0.4.4/24): боковое лицо/волосы отрисованы отдельно; нос в планке направлен вниз, волосы свисают по вертикали сцены. Передний/задний рисунок D075 сохранён. Новые планка/отжимание: общий коврик, предплечья/ладони и носки опираются на него. Отжимание — поворот прямого корпуса вокруг стоп, фиксированные кисти/стопы, 25 плавных ключевых кадров ограничивают изгиб при линейной интерполяции. Подтягивание — фиксированные кисти/перекладина, корпус поднимается, явный полюс локтя в передней плоскости. Источники NHS/NASM и пределы в D078/DECISIONS; собственные векторы, изображения источников не включены. Уже сохранённые пользовательские сцены/снимки не переписываются: новые шаблоны используются при создании и выборе базовой позы; для старой сцены требуется явная правка.

D075 (0.4.3/23): женский контур груди–талии–бёдер с явной точкой узкой талии, более тонкими конечностями и менее расклешённой юбкой. У обоих персонажей визуальная голова приближена к плечам для короткой шеи; координаты каркаса не изменены. Лицо/волосы движутся вместе, наклон головы прежний. Общие векторы без новых таймеров и форматов.

D074 (0.4.2/22): женская фигура — топ/мини-юбка, длинные отдельные боковые пряди и открытая шея; мужская — майка/шорты и короткие волосы. Голова следует вектору шея–голова, лицо использует фронт/профиль/затылок по общему yaw и torsoYaw. В планке нос профиля направлен вниз. Затылок не показывает глаза/рот. Это общая векторная иллюстрация Android/Windows, без новых данных/таймеров, без независимого параметра поворота лица и полноценной 3D модели.

3D точки проецируются ортографически при yaw; автоматический painter order по глубине каждого сегмента после поворота, дальние конечности за корпусом, ближние перед ним. Кисти/стопы/оборудование участвуют в порядке. Ручная поправка auto/back/front для части/предмета предназначена для неоднозначных пересечений, не отменяет остальные автоматические слои. Интерполяция координат линейная, углы кратчайшим путём. На последнем кадре без цикла остановка, статичная сцена не создаёт кадровый таймер. Один активный просмотр, 20 fps только Canvas, пауза/фон/выключение останавливают анимацию. Это редактор иллюстраций, не симулятор физики/биомеханики и не 3D mesh.

## Совместимость

Своя библиотека хранит ExerciseAsset(UUID/exercise/updated/deleted), максимум 100 записей, переносится в activity. Слияние выбирает новую ревизию по updated, равенство сохраняет местную; копии получают UUID. Сцены отдельно встроены в комплексы/историю, редактирование библиотеки не переписывает выполненные тренировки. Пока библиотека в JSON metadata SQL 2; отдельная нормализованная таблица до публичного релиза — дальнейшая работа.

Дополнения пользователя: поворот всей фигуры и корпуса независимо, обычные/вращающиеся стрелки и подписи, обруч/палки/скакалка/мяч/гиря/степ/блок/валик, несколько экземпляров. Турник прямой/параллельный/угловой. JSON `.fiteasy-rig.json` с format/version/clip — полный открытый обмен, до 1 MiB, без выполнения кода. SVG — редактируемый каркасный снимок с подписями, не импортируемая анимация. Публикуемые модели данных документированы в RigModel.kt/RigFiles.kt; Blender/glTF/BVH совместимость не заявляется.

Фиксирование длин по первому кадру включено, можно выключить для изменения пропорций. Двухсегментный IK для закреплённых кистей/стоп, недостижимая цель ограничивается досягаемостью без растяжения. Это геометрический ограничитель, не анатомическая безопасность. Редактор не выполняет полноценную физику, автоматическую проверку пересечений и сгибания пальцев; возможны неоднозначные пересечения при сильном вращении. Ручная поправка слоёв доступна. Длины/контакты используются при просмотре; authored координаты сохраняются, иначе редактирование было бы разрушающим.

Старая техника/текст пользователя сохраняются; старый рисунок больше не выводится, отсутствующая сцена предлагает редактор. Новые сцены входят в снимки упражнений/результатов комплексов и переносятся вместе с ними. LAN 6 / Transfer 5 требует обновления обоих клиентов; backup writer 5, reader 1–5. SQL схема 2 остаётся: дополнительное поле агрегатного JSON с default null, старые записи читаются без сцены. Android/Windows используют общий движок; Linux впоследствии тот же контракт. Ограничения/конечность координат/структура кадров проверяются до импорта/сохранения; внешний код или файлы сцена не исполняет.

D088 (0.4.14/34): редактор — сцена на весь экран, плавающая панель инструментов в четырёх положениях со скрытием, лист настроек вкладки поверх сцены; справочник листается стрелками.

D119 / 0.4.35/55: фигура упражнения — один целый человек в любой позе и с любой стороны. Плечи держатся на грудной клетке и наклоняются вместе с ней (rigTorsoFrame); силуэт соединяет плечи, бёдра и шею с туловищем, скелет — шею с позвоночником и бёдра с тазом. В редакторе виды: спереди, оба бока, сзади и сверху (RigPose.pitch, по умолчанию 0; rigProject с наклоном сцены). Общий код Android/Windows. Поле pitch необязательное: SQL 2, LAN 7, Transfer 5, backup 5 прежние; версия до 0.4.35 сцену читает, но показывает её без наклона.
