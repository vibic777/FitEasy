## Жизненный цикл

LocalData.legalNoticeVersion — целое 0..100000, default 0; текущий текст 1. Экран до дневника после успешной загрузки/разблокировки; запись версии только после нажатия и успешной транзакции. Обычный повторный запуск не показывает его снова. Старые установки тоже увидят новый текст. Полное обнуление all или выбор всех категорий сбрасывает версию до 0 и немедленно возвращает экран; частичное удаление и удаление демо сохраняют её. Внешние бэкапы не удаляются. Физическое wipeLocal удаляет БД и создаёт LocalData с 0. Импорт сырой DB сбрасывает привезённую версию в 0.

Это локальное поле JSON metadata SQL 2. В SharedData, LAN 6, Transfer 5, Backup 5 и Appearance поля нет. .fiteasy и синхронизация не подтверждают ознакомление за пользователя. Старый JSON без поля читается с 0; SQL migration не требуется. Будущее изменение текста увеличивает LEGAL_NOTICE_VERSION.
