# Справочники продуктов и блюд — D070

vibic777, 03.10.2026. Реализация входит в текущую работу Android и Windows.

Два отдельных справочника, один стабильный ID записи и общие нутриенты независимо от языка. Исходный язык своей записи — язык приложения при создании. Редактор переводов показывает исходный и целевой языки рядом; изменение перевода не меняет историю дневника. Интернет-перевод пока только план: AUTO_TRANSLATION_PLAN.md.

## Обмен справочниками

Открытый версионированный UTF-8 JSON `.fiteasy-catalogue.json`: маркер `fiteasy-catalogue`, версия 1, список выбранных категорий product/dish, записи с ID, нутриентами, происхождением и всеми переводами. Экспорт: оба справочника, только продукты, только блюда. Материализуются действующие записи встроенного справочника и пользовательские изменения; дневник, профиль, заметки, ключи и настройки не входят.

Импорт сначала полностью разбирается и проверяется вне UI, показывает состав и режим, затем применяется атомарно после подтверждения. Ошибка формата не меняет базу. Размер ограничен 32 MiB, не более 20000 записей; ID уникальны во всём файле, типы соответствуют выбранным категориям.

- Слияние: совпадение по ID, существующие значения сохраняются при равной ревизии; более новые изменения и переводы учитываются по правилам конфликта. Название не является идентификатором.
- Добавление копиями: каждому импортируемому элементу новый UUID; действующие записи сохраняются.
- Замещение: подтверждение с названиями выбранных категорий и количеством; меняются только эти справочники, другие данные не удаляются. Встроенные записи отсутствующие в импортируемой категории скрываются tombstone, иначе они появятся снова при загрузке stock. Исторические записи дневника сохраняют свои снимки нутриентов/названий; ссылки рецептов на исключённые записи требуют явной индикации отсутствия, без молчаливой подмены.

Для защиты от параллельных правок замещение проверяет снимок выбранных категорий перед применением; при изменении запросить повторный просмотр. Импорт не должен сбрасывать личные данные или распространять локальный wipe. Общая реализация и формат одинаковы на Android/Windows, пригодны для будущего Linux.
