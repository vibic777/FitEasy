Решение D-053, 2026-10-02, vibic777. Общий интерфейс Android/Windows: пять тем — спокойная, цветочная, воздушная, геометрическая и разноцветная. Различаются формами Material-компонентов, обводкой карточек, толщиной/подложкой значков и палитрами. Системная/светлая/тёмная схема выбирается независимо. Пользовательский акцент доступен в любой теме.

Цвет выбирается из палитры либо вводом RGB 0–255 / RRGGBB. Фоны разделов «Сегодня», «Питание», «Вода», «Активность», «Прогресс», «Профиль», «Настройки», «Расписания», «Календарь», «Заметки» независимы. Изменение применяется к выбранным галочками разделам или сразу ко всем. Подложки содержимого сохраняют читаемость; фон не заменяет текстовые цвета. Изображение подготавливается вне UI, до 1 MiB; суммарный предел уникальных изображений 8 MiB. Одинаковая картинка хранится один раз по SHA-256, несколько разделов ссылаются на неё. Неиспользуемые изображения удаляются при изменении настроек. Старый общий фон остаётся fallback до назначения фона раздела.

Appearance получает style, sectionBackgrounds и backgroundImages. Поля с default сохраняют чтение старых снимков. Оформление не передаётся по LAN, при backup включается отдельной галочкой. Новый файл с оформлением требует обновлённого клиента для сохранения этих полей при последующей перезаписи; SharedData, LAN protocol 4 / Transfer 3, backup envelope 3 остаются прежними. Полная совместимость старого клиента с новым оформлением не заявляется.

D084 (0.4.10/30): семь стилей — добавлены «Розовая» и «Фиолетовая». У стилей, кроме «Спокойной», заданы собственные чистые тона страницы, карточек и панелей для светлой и тёмной темы; подмешивание акцента в серый убрано. Значок и анимация раздела «Активность» — лёгкий бег.
