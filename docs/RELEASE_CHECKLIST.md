# Проверки перед первым выпуском

Составлено 10.10.2026 (0.4.36/56) из открытых пунктов TODO.md. Здесь только то, что нельзя подтвердить сборкой и
автоматическими тестами: нужен телефон, второй компьютер, почтовый сервер или взгляд владельца. Пункт отмечается после
фактической проверки, с датой, устройством и версией; результат записывается в ИСПРАВЛЕНИЯ.md.

## 1. Установка и запуск Windows

- [ ] Установка EXE и MSI на чистую систему; язык мастера на русской и английской Windows.
- [ ] Обновление поверх предыдущей версии: программа закрыта; программа работает (ответы «Да», «Нет», «Отмена»); тихая установка `/qn`.
- [ ] После обновления поверх работающей программы — перезагрузка и запуск (D122).
- [ ] Удалить одну библиотеку из папки `app`: появляется сообщение о повреждённых файлах, код завершения 3 (D122).
- [ ] Удаление: вопрос об удалении данных, ответ «Нет» сохраняет данные; тихое удаление сохраняет данные.
- [ ] Portable ZIP: запуск после распаковки, данные в своей папке `data`.
- [ ] Заголовок окна: перетаскивание, двойной щелчок, системное меню, масштаб 125–150 %.
- [ ] Плавность окна при отрисовке «Автоматически»; при артефактах — режим «Совместимость».
- [ ] Трей: правый щелчок, все пункты, восстановление окна, смена языка, «Заглушить».

## 2. Телефон: запуск и интерфейс

- [ ] Release APK (R8) запускается; обновление поверх предыдущей сборки с тем же ключом подписи.
- [ ] Маленький экран и горизонтальная ориентация; длинные переводы; размер текста системы.
- [ ] Долгое нажатие на значках (в том числе в прокручиваемых списках), нажатие на подсказку открывает справку.
- [ ] Страницы редактирования занимают весь экран, клавиатура не закрывает поля.
- [ ] Семь стилей в светлой и тёмной теме (и на Windows).
- [ ] «Настройки → Права»: «Разрешить» и «Отозвать» у каждого из четырёх прав, «Отозвать все права»; уведомления отозваны после закрытия приложения (D127).
- [ ] Имя на рабочем столе: «ФитИзи» при русском языке системы, «FitEasy» при другом (D128).
- [ ] Редактор каркаса пальцем: суставы, ручки кистей и ступней, пять видов; свои упражнения с наклонённым туловищем (D119).
- [ ] Справочник упражнений: 15 карточек, оценка фигур и движений владельцем (D126).
