# PDF и CSV

Выберите начальную/конечную дату включительно и галочки питания, напитков, шагов, активности, замеров. Экспорт исключает корзину и содержит канонические единицы. CSV: UTF-8 BOM, кавычки, защита значений от формул таблиц; неизвестные нутриенты пустые, известные нулевые значения остаются нулями. Включены клетчатка, приём пищи, источник и время/завершение комплекса.

PDF содержит даты, записи, количество/единицы, известные нутриенты, источник и этапы снимка комплекса. Создаётся на устройстве. Android — системный PdfDocument; Windows — страницы Java2D в стандартном PDF с JPEG изображениями. Windows текст не выделяется, отображение символов зависит от установленных шрифтов. Общие пределы: 10000 записей и 250 страниц; большие отчёты завершаются ошибкой, данные не обрезаются. Создание выполняется вне потока интерфейса.

Отчёт не восстанавливает базу. Для переноса используйте .fiteasy. Заголовки PDF пока требуют полной локализации. Графики в PDF и выбор альтернативных единиц ещё не подключены. Компиляция выполнена; визуальная проверка экспортированных страниц не выполнена.
