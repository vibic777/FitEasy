# Заметки — уточнение vibic777, 2026-10-02

## D067 — 0.3.11/18

Явные режимы «Все заметки» и «По папкам». Все заметки включает перемещённые записи без фильтра папки. Браузер показывает непосредственные карточки папок и «Без папки», прямой вход/возврат, создание кнопкой плюс; управление названиями/удалением отдельно. Пользователь подтвердил линейную структуру одного уровня без вложенных папок.

Сортировка по имени/созданию/изменению/типу, любое направление; отдельно сохраняется для всех, без папки и каждой папки. Папки — имя/создание/изменение/количество активных заметок. Неизвестное created последнее при обоих направлениях, равенство разрешает UUID; корзина исключена из счётчика. Настройки локальны в NoteDisplay, не передаются LAN; старые значения читаются с defaults. Ключи сортировки и счётчики вычисляются один раз на изменение, не на каждое сравнение/кадр. Иконки видов/сортировки/папок с подсказками на десяти языках, выбранный вид выделяется. Форматы SQL 2/LAN 5/backup 4 не меняются.

0.3.8/15: при создании текстовой/рисованной/списочной заметки и папки сразу предлагается имя на выбранном языке с первым свободным положительным номером. «Папка 1, 3, 4» → «Папка 2»; «1, 2, 3» → «4». Сравнение без регистра/краевых пробелов, среди активных записей; заметки учитываются во всём дневнике. Название можно изменить до/после сохранения; идентичность и LAN опираются на UUID, не имя. Параллельное создание на двух устройствах может дать одинаковые имена, это не конфликт UUID.

### D-051 — папки, виды и штампы (0.3.0/7)

Заметки получают folderId и необязательное created. Для старых заметок создание неизвестно: не подставлять время загрузки. Новые заметки/копии имеют новое время создания; изменение/перемещение меняет updated. Отдельные переключатели времени создания/изменения заметок и папок соответствуют подходу Notio StampOptions. Формат отображения локализованный, зона устройства; хранятся UTC epoch milliseconds. Показ штампов — локальное оформление.

Папки плоские, UUID/name/created/updated/deleted; добавление, переименование, удаление. Удаление папки отвязывает заметки, не удаляет их. Фильтры: все типы / текст / рисунки / списки; все без учёта папок / без папки / выбранная папка. Виды: подробные карточки, компактный список, сетка; поиск/корзина работают с фильтрами. Перемещение одной заметки выбирает папку либо корень.

Папки включены в LAN notes и .fiteasy. Копирование бэкапа переназначает UUID папок и ссылки заметок. Transfer 3, LAN protocol 4 не допускают старый клиент, который мог бы потерять папки; обновить оба клиента. Backup writer 3, reader 1–3. SharedData получает необязательный noteFolders; SQLite DDL неизменен. Reset notes очищает папки тоже. Показ/фильтры не меняют содержание заметок. Источник идеи: Notio-Android StampOptions, четыре независимых переключателя; своя реализация.

Папка «Заметки» содержит три вида: текстовая заметка, рисунок, список с галочками. Название, содержимое, порядок пунктов/штрихов, стабильные UUID, время изменения и tombstone переносимы Android ↔ Windows, позже Linux. Флажок пункта списка — данные, не локальное оформление. Рисунок хранится в нормализованных координатах; размер экрана не меняет геометрию. Редактор поддерживает цвет/толщину, отмену последнего штриха и очистку с подтверждением. Текст — простой многострочный, богатое форматирование отдельно.

Расписания остаются отдельной папкой. Напоминания заметок не включаются автоматически: текущая привязка — строки расписания. Заметки не содержат ключей/паролей. Общий контракт содержит раздел LAN notes, перенос через бэкап, копирование с новыми UUID и сохранение удалений. Практическая проверка остаётся открытой.

Референс Notio — ListDocument.kt и feature/drawing/VectorModel.kt, поведение редакторов; свои модели/UI, без копирования исходников и рисунков. Подключены общий редактор текста, свободное рисование с цветом/толщиной/отменой, список с галочками/комментарием/порядком, поиск, копии, корзина/восстановление. Полотно квадратное, до 2000 штрихов/100000 точек на рисунок; до 1000 пунктов списка. LAN sections notes, бэкап v2; старые данные получают пустые списки. Богатое форматирование, фигуры/заливка/слои Notio, экспорт рисунка и восстановление незавершённого редактора пока отсутствуют. Сохранение явной кнопкой; перед фоном/блокировкой сохраните изменения. Windows выход предупреждает о несохранённой заметке.
