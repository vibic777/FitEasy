# Формулы и ограничения

Энергетический ориентир: упрощённая формула Миффлина — Сан Жеора из [исходного исследования](https://pubmed.ncbi.nlm.nih.gov/2305711/). Покой = 10 × кг + 6,25 × см − 5 × возраст + 5 для мужчин либо −161 для женщин. Суточный ориентир — покой × выбранный пользователем коэффициент активности. Дефицит автоматически не назначается. Доступный диапазон возраста 19–78; исходные данные/проверки/коэффициент видны пользователю, результат является оценкой.

ИМТ = кг / метры². Числовой взрослый ориентир показывается только при введённом возрасте не менее 20 лет, без автоматической диагностики или категорий. [CDC: формула и возрастная применимость](https://www.cdc.gov/bmi/adult-calculator/).

Автопересчёт и применение без подтверждения выключены по умолчанию. При изменении входов создаётся новое предложение; исходные данные и факт применения сохраняются. При подтверждении сохраняется история цели, прошлые записи не изменяются. Пользователь может оставить ручную цель.

Android и Windows используют один исходный код формул и одни единицы.
