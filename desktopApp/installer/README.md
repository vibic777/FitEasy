# Windows packaging

0.3.9: локализованный вопрос Да/Нет/Отмена при удалении, Нет по умолчанию. /qn сохраняет данные; FITEASYDELETEDATA=1 — явное удаление текущего LOCALAPPDATA/FitEasy. Перед silent удалением закрыть программу. Действие только после успешного InstallFinalize и не при UPGRADINGPRODUCTCODE/repair; сначала exact target/reparse/locked-file preflight. Внешние backup/portable/другие профили не затрагиваются. Проверка MSI не удаляет реальную базу и не выполняет установку.

`packageManagedMsi` и `packageManagedExe` создают установщики с собственным диалогом проверки запущенной установленной копии. Gradle извлекает стандартный шаблон main.wxs из jdk.jpackage.jmod используемой JDK в build/, вставляет hooks.xml и кодирует close-running.ps1. Шаблон JDK не копируется в исходники.

Сценарий проверяет полные пути из Windows uninstall registry (FitEasy, Publisher vibic777). Автоматический вариант отправляет аутентифицированную loopback-команду штатного выхода; ручной ждёт закрытия и повторной проверки; отмена возвращает ошибку до ExecuteAction. Принудительного Stop-Process нет. Старые версии без IPC требуют ручного закрытия. Диалог предназначен для интерактивной установки; silent установка использует обычную политику MSI/Restart Manager. Интеграция установщика требует отдельной проверки на Windows с установленной/работающей предыдущей версией.
