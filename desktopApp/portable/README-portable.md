# FitEasy portable — Windows

Распакуйте весь архив в отдельную доступную для записи папку и запустите FitEasy.exe. Встроенный runtime входит в архив; установка Java не нужна. Не запускайте приложение из окна архиватора.

При первом запуске создаётся data рядом с FitEasy.exe. Установленная версия хранит данные отдельно в LOCALAPPDATA/FitEasy. Для обновления завершите приложение, распакуйте новую версию, сохранив свою папку data. Второй запуск той же копии поднимает первое окно; разные папки данных независимы.

Пароли/ключи защищены Windows DPAPI и связаны с пользователем/машиной. Portable означает запуск без установки; перенос между компьютерами выполняйте через .fiteasy, с настройкой защиты на новом компьютере. Архив поставки не содержит ваших данных.
