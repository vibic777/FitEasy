Dependency licenses and catalogue sources must be finalized before public distribution. No Notio signing secrets are included in this repository.

The following implementations are adapted from the local Notio-Windows shared JVM sources (same author's Notio code): SyncCrypto.kt, SyncSession.kt, CredentialHasher.kt, Totp.kt and SmtpClient.kt. Package names are changed to com.fiteasy.shared. The complete upstream MIT notice is preserved in docs/licenses/Notio-MIT.txt and must accompany distributions.

Discovery.kt is also adapted from Notio-Windows, with a separate _fiteasy-sync._tcp.local. service type. FitEasy does not connect to Notio's data protocol.

Android BiometricAuth.kt is adapted from Notio-Android, using the platform prompt and adding explicit completion callbacks.

FitTheme.kt reuses the named palette accent values from Notio-Android core/ui/theme/Color.kt and Notio-Windows desktop/theme/Colors.kt (MIT, Copyright (c) 2026 vibic777). FitEasy implements its own surface/container composition. IconAction.kt follows their accessible tooltip interaction pattern; the FitEasy canvas icons are original. The full MIT notice accompanies distributions in docs/licenses/Notio-MIT.txt.

Managed Windows installers include unmodified WiX DTF runtime/SfxCA and standard WiX UI translations, Copyright (c) .NET Foundation and contributors, under MS-RL. The full license is included as docs/licenses/WiX-MS-RL.txt and packaged licenses/WiX-MS-RL.txt. The Belarusian WiX UI translation in desktopApp/installer/be.json and generated WiX localization resources are also provided under MS-RL. FitEasy's independent installer code and own messages remain separate sources. Build provenance: WiX 3.11 archive already used by Compose packaging; upstream https://github.com/wixtoolset/wix3.

Android ReminderRing.kt (ReminderRingService, ReminderSounds) and the shared ringGain function in Reminders.kt are adapted from Notio-Android core/notification/ReminderRingService.kt, ReminderSounds.kt and domain/model/RingRamp.kt (MIT, Copyright (c) 2026 vibic777): foreground melody playback on the alarm stream with its own volume, fade-in and audio focus, and copying a chosen audio file into the app. FitEasy plays copied files itself and therefore uses no FileProvider. The reminder cards, the reminder editor and the synchronization page follow the layout of the Notio screens with independent code.

shared sync/SyncEngine.kt and sync/SyncStore.kt (with SyncAddress) are adapted from Notio-Windows shared/sync (MIT, Copyright (c) 2026 vibic777): listening while the page is open, pairing by code, paired syncs with a question on the other device, test connection, unpairing on both devices and the log. FitEasy moves its sections instead of folders and keeps the pairings in one device secret. shared NotioStrings.kt is generated by tools/import_notio_strings.py from the Notio-Android string resources in ten languages (MIT, same copyright); the product name in those texts is replaced by FitEasy. The settings pages Security and privacy and Backup follow the layout of Notio's pages with independent code.

shared NotioIcons.kt is copied from Notio-Windows desktop/AppIcons.kt (MIT, Copyright (c) 2026 vibic777); its path data are Material Icons 1.7.8, Copyright Google LLC, Apache License 2.0. The trash, help and about pages follow the layout of the Notio screens with independent code.

Third-party libraries added with 0.4.36: ZXing core 3.5.4 (QR code of the TOTP key; Copyright ZXing authors, Apache License 2.0, https://github.com/zxing/zxing) on Android and Windows. Windows only, each kept as its own unmodified jar in the app folder so it can be replaced: MP3SPI 1.9.5.4 and JLayer 1.0.1.4 (Copyright JavaZOOM, LGPL 2.1, http://www.javazoom.net), Tritonus Share 0.3.7.4 (LGPL 2.1, http://www.tritonus.org) and JOrbis 0.0.17.4 (Copyright JCraft Inc., LGPL 2.1, http://www.jcraft.com/jorbis) decode MP3 and OGG Vorbis melodies of reminders. FitEasy's own OggVorbis.kt follows the page-reading order of the JOrbis decoding example. The texts of these licenses must accompany a public distribution.
