# FitEasy

[English](README.md) · **Русский**

> Дневник похудения, выросший из домашней просьбы. Задание осталось мягким. Интересное уже видно.

**FitEasy** начался с личной просьбы: нужен был дневник похудения. Его так и не сформулировали до конца, поэтому проект растёт из идей, которые появляются по ходу.

Уже хочется оставить и развить:

- редактор упражнений, которым может пользоваться любой человек
- комплексы, собранные под себя
- базу движений, которую можно пополнять
- упражнения с анимацией

Цель — вещь, которую приятно открывать каждый день. До неё ещё далеко: много нюансов, часть сделанного пока не нравится, и работа буксует. Это MVP, который ищут руками.

Первые клиенты — Android и Windows. Linux может появиться позже. Данные, резервные копии и синхронизация у клиентов должны оставаться совместимыми. Согласованный объём ещё не закрыт.

Для сборки Android и Windows нужен JBR/JDK 25 и настроенный Android SDK. Из корня проекта выполните:

    .gradlew.bat :desktopApp:packageDelivery

Путь к SDK задаётся в локальном local.properties, ключ подписи — в keystore.properties. Не добавляйте их в Git. Резервные копии и синхронизация между клиентами требуют совместимых версий.

Подробные сведения о статусе, архитектуре, схеме базы и синхронизации приведены в основном README и каталоге docs/.
